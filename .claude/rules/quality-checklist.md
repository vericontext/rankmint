# Quality Checklist for HTML Output

Every HTML page generated by RankMint MUST include:
1. Navigation: Home link (← RankMint Home → ../) at the top
2. Navigation: Back link to parent page if not the site root
3. OG meta tags: og:title, og:description, og:image
4. No duplicate items in tier/category lists — KNOWN BUG: `TIERS.find(t => t.min > tier.min)` returns wrong boundary when TIERS array is not sorted ascending. Always sort tiers by min descending before filtering, or use `Math.min(...TIERS.filter(t => t.min > tier.min).map(t => t.min))` for nextMin
5. No CSS text truncation on content text
6. RankMint watermark on charts
7. Mobile responsive (375px minimum)
8. Desktop centering: ALL content sections (.container, .chart-section, .taxonomy, .full-table, .find-yourself, .methodology, .findings) MUST use `margin: Npx auto` (NOT `margin: Npx 0`). Using `0` instead of `auto` for horizontal margin breaks desktop center alignment.
9. Container max-width: `.container` must be `max-width: 1200px; margin: 0 auto;` — never narrower than 1200px
10. Social share: Use "Share on X" (not Twitter), URL `x.com/intent/post`, button color `#000`
